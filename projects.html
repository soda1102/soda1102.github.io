04. Troubleshooting

문제 해결 사례를 클릭하면 과정이 펼쳐집니다.

데이터셋 클래스 불균형 문제

Problem 특정 동물 클래스의 라벨 수가 다른 클래스에 비해 지나치게 많았습니다.

Cause 데이터 증강 설정으로 클래스 불균형이 심화되었습니다.

Solution 탐지 클래스를 멧돼지·너구리·고라니 3종으로 재구성하고, 전처리를 조정한 뒤 YOLO 자체 증강으로 재학습했습니다.

옵티마이저 비교 · SGD vs AdamW

Problem 모델 학습에 적합한 옵티마이저를 선택해야 했습니다.

Cause AdamW는 수렴 속도가 빨랐지만 과적합 경향을 보였습니다.

Solution 두 옵티마이저를 비교 실험하고 일반화 성능을 고려해 SGD를 최종 선택했습니다.

GPU 학습 환경 문제

Problem Colab GPU의 성능과 이용 시간에 제약이 있었습니다.

Cause 모델 학습이 장시간 진행되면서 컴퓨팅 자원이 부족했습니다.

Solution Vast.ai 환경을 거쳐 자체 GPU RTX 4070 Ti를 활용하도록 학습 환경을 변경했습니다.

04. Troubleshooting

DB · 백엔드 필드명 불일치 문제

Problem 관리자 대시보드에서 API 호출은 성공했지만 일부 데이터가 표시되지 않았습니다.

Cause Flask API 응답의 필드명과 DB 컬럼명이 일치하지 않아 프론트엔드에서 값을 정상적으로 매칭하지 못했습니다.

Solution 백엔드 코드와 데이터 구조를 확인해 필드명 불일치를 수정하고, 화면에서 정상적으로 출력되는지 재검증했습니다.
