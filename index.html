troubleshoot.md

MINI PROJECT · 도(道)서관 — AI 데이터셋 작업 중 겪은 문제들

DATA

데이터셋 클래스 불균형 문제

Problem동물 탐지 모델 학습 중 클래스별 라벨링 수가 크게 어긋난 걸 발견 (예: 산토끼류 3,467개 vs 다른 클래스 500개 내외).

Cause과도한 전처리(로보플로 증강) 옵션 사용으로 데이터셋이 비정상적으로 생성됨.

Solution클래스를 3종(멧돼지·너구리·고라니)으로 재구성하고 전처리를 걷어낸 뒤, YOLO 자체 증강 옵션으로 재학습해 과대적합을 줄임.

AI MODEL

옵티마이저 선택 (SGD vs AdamW)

ProblemYOLO 학습 시 어떤 옵티마이저가 더 안정적인 성능을 내는지 확인이 필요했음.

CauseAdamW는 수렴은 빨랐지만 학습 데이터에 과도하게 맞춰지는(과적합) 경향을 보임.

Solution100 epoch 기준 SGD와 AdamW를 직접 비교 실험해, 일반화 성능이 더 좋은 SGD를 최종 채택 — mAP를 유의미하게 개선.

INFRA

GPU 학습 환경 트러블슈팅

ProblemColab 무료(T4)는 성능 부족, Colab Pro는 16시간 만에 컴퓨팅 단위가 소진되며 학습이 강제 종료됨.

Cause무료/사설 GPU 환경의 성능·시간 제약으로 장시간 학습이 불가능했음.

SolutionVast.ai(RTX 5090)를 거쳐 최종적으로 자체 GPU(RTX 4070Ti)로 전환해 안정적인 학습 환경을 확보.

FINAL PROJECT · Weather-AI — 프론트엔드·백엔드 연동 중 겪은 문제

DATA SYNC

DB-백엔드 필드명 불일치로 데이터 미표시

Problem관리자 대시보드에서 API를 정상 호출했는데도 일부 데이터가 화면에 표시되지 않음.

CauseFlask API 응답의 필드명과 실제 DB 컬럼명이 서로 달라 프론트에서 값을 제대로 매칭하지 못함.

Solution백엔드 코드를 직접 확인해 필드명 불일치 구간을 찾아 수정하고, 프론트와 정상 연동되는지 재검증함.
